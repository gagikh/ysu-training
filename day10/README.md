# Օր 10. Առաջարկների քննարկում

## Ձևաչափ

Մասնակիցները ներկայացնում են ուսանողական աշխատանքների առաջարկներ, որոնք պատրաստել են դասընթացի ընթացքում, և խումբը քննարկում է դրանք։ Առաջարկները կարող են լինել երեք տեսակի.

- կուրսային աշխատանք
- դիպլոմային աշխատանք
- մագիստրոսական թեզ

Ձևի և ծավալի պարտադիր պահանջներ չկան։ Ամեն մասնակից ինքն է որոշում, թե ինչ ներկայացնի։ Առաջարկը կարելի է վերցնել անմիջապես [`topics-bank.md`](topics-bank.md)-ից, հարմարեցնել այնտեղի թեմաներից մեկը կամ գրել նորը։

## Քննարկման թեմաները

Քննարկվում են այն հարցերը, որոնք բարձրացնում են առաջարկները։ Օր 1–9-ի նյութը խմբի ընդհանուր հիմքն է. կլաստերի GPU-ի իրական պարամետրերը (Օր 1), profiling-ի մեթոդը (Օր 3 և Օր 6), գրադարանների և ճշգրտության փոխզիջումները (Օր 9)։
